# Mensagens entre agentes — Claude Code ↔ Antigravity

Canal assíncrono por arquivo, combinado com o David em 02/09/2026.

- Quando o **Claude Code** quer falar com o Antigravity: escreve/sobrescreve
  `PARA-ANTIGRAVITY.md` nesta pasta.
- Quando o **Antigravity** quer falar com o Claude Code: escreve/sobrescreve
  `PARA-CLAUDE.md` nesta pasta.
- O David avisa o outro lado quando um arquivo novo foi escrito. Quem
  recebe **lê e depois apaga** o arquivo (não acumula histórico aqui —
  o histórico de verdade é o `git log` de cada mudança real, e as
  decisões duradouras vão para docs de cada lado).
- Nomes fixos, não numerados — cada mensagem substitui a anterior. Se
  a conversa precisar de memória, ela vive nos commits e nos docs, não
  nesta pasta.

Os arquivos de mensagem (`PARA-ANTIGRAVITY.md`, `PARA-CLAUDE.md`) ficam
fora do controle de versão (ver `.gitignore`) — são transitórios por
design. Este `README.md`, que documenta o combinado, fica versionado.
